# THIS FILE IS NOT A PLAIN `pip install -r requirements_hssim.txt` ON ITS OWN. Three things need
# special handling, all real landmines this project's own README already warns about one of:
#
# 1. TORCH/TORCHVISION are CUDA 12.8 wheels (the `+cu128` local-version suffix) -- PyPI's default
#    index does not host these. Install them FIRST, from PyTorch's own index, matching your
#    target machine's CUDA driver:
#        pip install torch==2.7.0+cu128 torchvision==0.22.0+cu128 \
#            --extra-index-url https://download.pytorch.org/whl/cu128
#    If the new server has a different CUDA driver version, pick the matching PyTorch wheel
#    instead of forcing cu128 -- a mismatched build will fail to find a GPU at import time, not
#    at install time.
#
# 2. ISAACSIM (the isaacsim-* block below, NVIDIA Isaac Sim 5.1.0.0) is NOT on plain PyPI either:
#        pip install isaacsim==5.1.0.0 isaacsim-app==5.1.0.0 --extra-index-url https://pypi.nvidia.com
#    (or install every isaacsim-* line below the same way). Isaac Sim also expects
#    `OMNI_KIT_ACCEPT_EULA` set and has its own first-run asset download -- see this project's
#    `scripts/source_isaacsim_setup.sh` and README Setup section, this file only covers the
#    Python package layer.
#
# 3. HOLOSOMA -- the raw `pip freeze` output for this package is actively WRONG and has been
#    OMITTED below rather than reproduced. Its recorded editable-install source is:
#        -e git+https://github.com/hanifsyarubany/RoboJuDo-real.git@{commit}#egg=holosoma&subdirectory=.../locomotion_and_ball_kicking/src/holosoma
#    That points at a DIFFERENT sibling fork of holosoma than this project actually runs (the
#    same "training against the wrong env silently runs the wrong code" trap this project's own
#    src/holosoma/README.md warns about for the `hssim_holosoma` conda env -- pip's own metadata
#    fell into the identical trap here). The correct install, once this repo is on the new
#    server, is THIS project's own copy:
#        cd unified_ball_kick_enhanced/src/holosoma && pip install -e .
#
